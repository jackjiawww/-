# Windows 真人桌宠 0.2.0

透明、置顶的照片桌宠。无需账号、API 密钥或 Node.js 即可运行打包版。

## 下载并运行

在 GitHub 打开 `downloads/DesktopPet-Windows-x64.exe`，点击 Download raw file，下载到 Windows 10/11 64 位电脑，再双击。
更新前必须先退出旧版（如果旧版菜单不可用，在任务管理器中结束 DesktopCat）。
顶部应显示 `v0.2.0`，底部显示互动按钮和 5 个零食按钮。

## 玩法

- 点击人物或「戳一戳」：人物晃动，切换惊讶照片并显示回应；多次戳会有不同台词。
- 点击「摸摸」：轻轻摇动，切换微笑照片。
- 🍪 饼干：开心蹦跳。
- 🍓 草莓：微笑、轻轻摇动。
- 🍋 柠檬：酸酸的表情气泡和摇头动作。
- 🌶️ 辣椒：辣辣的表情气泡和快速蹦跳。
- 🍦 冰淇淋：舒服的表情气泡和缓慢摇动。
- 反应约 3 秒后恢复；连续操作会替换上一反应。互动和喂食会唤醒休息中的人物。
- 按住顶部「拖动移动」条移动窗口；人物区域用于点击互动。
- 「菜单」可以换图、休息/唤醒、切换置顶、恢复位置或退出。

默认素材包括根据用户照片生成的普通、微笑、惊讶三种静态表情，动作通过窗口内动画实现，不是真人视频。
更换自定义照片后保留动作、台词和表情气泡，不会自动生成该照片的脸部表情。选图保存在本机用户数据目录，重启后恢复。

## 从源码运行或打包

安装 Node.js 22 或 24 LTS，在项目目录打开 PowerShell：

```powershell
npm ci
npm run check
npm test
npm start
npm run dist:win
```

便携程序输出到 `dist`，未配置代码签名。云端已验证交互逻辑和 Windows 打包，但透明窗口、原生拖动、按钮位置和多显示器仍需要 Windows 实机验收。
